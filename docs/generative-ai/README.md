# External Generative AI Workflow

This folder contains prompt briefs and export guidance for external tools used to
support the immersive portfolio redesign.

Use these tools for:
- concept exploration
- composition and spatial ideation
- prompt development
- narrative refinement

Do not use them for:
- final app architecture
- UI behavior
- accessibility
- performance tuning
- routing
- content hierarchy

Recommended workflow:
1. Refine narrative, scene logic, and prompts in ChatGPT or Claude.
2. Generate broad concepts and section composition in Figma Make or Gemini.
3. Lock the world style and section hierarchy before implementing live UI.
4. Translate approved concepts into React components and static assets.

# ChatGPT / Claude Prompt Brief

## Goal

Use ChatGPT and Claude as creative direction and prompt-development partners for
the immersive portfolio redesign before any live implementation work begins.

These tools should help with:
- brand narrative refinement
- scene-by-scene concept development
- prompt writing for Figma Make and Gemini
- content editing and narrative compression
- interaction and worldbuilding planning

These tools should not replace:
- final React implementation
- accessibility work
- GitHub Pages deployment constraints
- performance tuning

## Prompt: Brand Narrative Refinement

```text
Help me refine the creative direction for my personal portfolio website. The site should be a dream-like, immersive, game-like but elegant static web experience with a living computational garden theme. It must reflect me as a researcher, systems thinker, AI/ML-curious builder, and designer. I want a strong personal brand that feels pristine, emotionally memorable, intelligent, and cohesive, not childish, noisy, or gimmicky. Please refine the brand narrative, tone, symbolic motifs, and visual storytelling language.
```

## Prompt: Scene Map Development

```text
Help me define a scene-by-scene experience map for a static portfolio website set in a living computational garden. The experience should include a homepage gateway, research zone, projects zone, experience zone, about sanctuary, and contact ending. For each zone, define the emotional goal, spatial concept, key visual motifs, content type, character presence, and how the user should move through it.
```

## Prompt: Character System Refinement

```text
Help me refine a visual narrative system for a stylized 3D avatar of me, supporting NPCs, and symbolic animal companions for an immersive portfolio website. The world is a living computational garden, so every character should reinforce my identity as a thoughtful researcher, systems thinker, designer, and builder of clarity. Please define character archetypes, emotional roles, stylistic rules, and what to avoid so the result does not feel like a random fantasy game.
```

## Prompt: Recruiter-Friendly Structure

```text
Help me balance an immersive 3D portfolio experience with professional clarity. I want recruiters, collaborators, and faculty to understand who I am, what I work on, and how to contact me within a few interactions. Please propose a clear information architecture and UI overlay strategy that preserves the dream-like world while keeping navigation practical and legible.
```

## Good Enough Before Integration

- clear creative direction
- scene logic that can be implemented in code
- concise, reusable prompt language
- agreement on what the world should communicate

Do not spend time generating final production code in these tools yet.

Place production-ready 3D model assets here.

Directory layout:
- `avatar/` for the main Irene avatar and close-up variants
- `npcs/` for supporting domain characters
- `creatures/` for companion animals and ambient creature assets
- `environments/` for reusable world props, terrain, and structural models

Preferred formats:
- `.glb` for runtime-ready web assets
- baked textures in `.webp` or `.png`
- optional review renders in `.png`

Guidelines:
- Keep filenames lowercase and kebab-case
- Prefer one asset per folder when textures are bundled alongside a model
- Export mobile-safe variants when polygon count is high
